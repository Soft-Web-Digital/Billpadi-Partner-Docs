Electricity Bill Payment

Pay prepaid and postpaid electricity bills across all Nigerian Electricity Distribution Companies (DISCOs) with instant token generation and webhook callbacks.

Base path/api/v1/partner/electricity
Authx-api-key (+ x-signature on purchase)
Required Scopeelectricity · Check requirements in Settings →
Supported Meter Typesprepaid · postpaid
Rate limit30 requests / 60s (failure circuit breaker)

2. Pay an Electricity Bill

Purchase electricity for a prepaid meter or settle a postpaid account. The providerId field accepts either the DISCO slug (e.g. ikeja-electric) or the MongoDB ObjectId:

Pay electricity bill

POST /partner/electricity/purchase
Signature required
FieldTypeRequiredDescription
meterNumberstringrequiredPrepaid or postpaid meter number
providerIdstringrequiredDISCO slug code (e.g. ikeja-electric, eko-electric) or ObjectId
amountnumberrequiredPayment amount in NGN (min 500)
meterTypestringrequiredprepaid or postpaid
phonestringrequiredCustomer phone number for SMS token delivery
partnerReferencestringrequiredUnique reference string (2–100 characters) for idempotency
cURL
Node.js
curl -X POST https://partner-api.billpadi.com/api/v1/partner/electricity/purchase \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "meterNumber": "04123456789",
    "providerId": "ikeja-electric",
    "amount": 5000,
    "meterType": "prepaid",
    "phone": "08012345678",
    "partnerReference": "PR-ELEC-77120"
  }'
const res = await partnerClient.post("/electricity/purchase", {
  meterNumber: "04123456789",
  providerId: "ikeja-electric",
  amount: 5000,
  meterType: "prepaid",
  phone: "08012345678",
  partnerReference: "PR-ELEC-77120"
});
Example response — 200 OK
{
  "success": true,
  "message": "Electricity purchase initiated",
  "data": {
    "transactionReference": "TXN_1720603200000_8F9A",
    "partnerReference": "PR-ELEC-77120",
    "status": "pending",
    "meterNumber": "04123456789",
    "amount": 5000,
    "token": "4123 9081 2234 5678 9012",
    "units": "54.2 kWh"
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/electricity/purchase"
}

For prepaid meters where the DISCO generates the token asynchronously, our background poller queries the carrier and dispatches an electricity.purchase.success webhook containing the token as soon as it is generated — see Webhooks.
