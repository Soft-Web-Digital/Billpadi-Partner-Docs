Product · Entertainment

Cable TV

Verify customer smartcards, browse bouquets, and renew or upgrade subscriptions across DSTV, GOtv, StarTimes, and Showmax.

Base path/api/v1/partner/cabletv
Authx-api-key (+ x-signature on verify/purchase)
Required Scopecabletv · Check requirements in Settings →
Supported CarriersDSTV (dstv) · GOtv (gotv) · StarTimes (startimes) · Showmax (showmax)
Rate limit30 requests / 60s (failure circuit breaker)

1. List Cable TV Providers

Query the supported pay-TV operators and their slug identifiers:

List cable TV providers

GET /partner/cabletv/providers
API key only

curl https://partner-api.billpadi.com/api/v1/partner/cabletv/providers \
  -H "x-api-key: $API_KEY"

3. Verify Smartcard Number

Always verify a customer's smartcard or IUC number before initiating payment. This resolves the registered customer name and current active bouquet:

Verify smartcard / IUC

POST /partner/cabletv/verify
Signature required
FieldTypeRequiredDescription
smartCardNumberstringrequiredDecoder smartcard or IUC number
serviceCodestringrequiredProvider slug: dstv, gotv, startimes, or showmax
cURL
Node.js
curl -X POST https://partner-api.billpadi.com/api/v1/partner/cabletv/verify \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "smartCardNumber": "1234567890",
    "serviceCode": "dstv"
  }'
const res = await partnerClient.post("/cabletv/verify", {
  smartCardNumber: "1234567890",
  serviceCode: "dstv"
});
Example response — 200 OK
{
  "success": true,
  "message": "Smartcard verified successfully",
  "data": {
    "smartCardNumber": "1234567890",
    "customerName": "CHINEDU OKEKE",
    "currentPlan": "DStv Yanga",
    "dueDate": "2026-07-28"
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/cabletv/verify"
}

4. Renew or Change Subscription

Submit a subscription payment for renewal or package upgrade:

Renew or change subscription

POST /partner/cabletv/purchase
Signature required
FieldTypeRequiredDescription
providerstringrequiredProvider slug: dstv, gotv, startimes, or showmax
smartCardNumberstringrequiredCustomer smartcard number
productIdstringrequiredTarget package code or MongoDB id from packages catalog
typestringrequiredrenew (keep current plan) or change (upgrade/downgrade bouquet)
partnerReferencestringrequiredUnique reference string (2–100 characters) for idempotency
cURL
curl -X POST https://partner-api.billpadi.com/api/v1/partner/cabletv/purchase \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "provider": "dstv",
    "smartCardNumber": "1234567890",
    "productId": "dstv-compact",
    "type": "change",
    "partnerReference": "PR-CTV-40218"
  }'
Example response — 200 OK
{
  "success": true,
  "message": "Cable TV subscription initiated",
  "data": {
    "transactionReference": "TXN_1720603200000_2B3C",
    "partnerReference": "PR-CTV-40218",
    "status": "pending",
    "smartCardNumber": "1234567890",
    "package": "DStv Compact",
    "amount": 15700
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/cabletv/purchase"
}

Upon carrier activation, Billpadi fires a cabletv.purchase.success webhook.
