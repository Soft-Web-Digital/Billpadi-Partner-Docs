Webhooks

Webhooks eliminate polling by pushing real-time notifications directly to your HTTPS endpoint whenever transactions complete, bank payouts settle, or asynchronous reviews resolve.

Configuring your webhook URL

You can configure or update your webhook URL using your authenticated partner dashboard token. Both PATCH /partner/webhook and GET /partner/profile return your unique webhookSecret, which you use to verify that incoming webhook payloads originate from Billpadi.

Your webhookSecret is also accessible at any time via GET /partner/profile under data.partner.webhookSecret.

Verifying webhook signatures

Every webhook HTTP POST sent by Billpadi includes cryptographic headers to prevent spoofing and tampering. Signatures are computed using HMAC-SHA256 with your webhookSecret:

HTTP HeaderDescription
X-Webhook-SignatureHexadecimal HMAC-SHA256 digest of {timestamp}.{rawBody}
X-Webhook-TimestampEpoch millisecond timestamp of notification dispatch
Node.js / Express
Python / FastAPI
PHP
const express = require("express");
const crypto = require("crypto");

const app = express();
const WEBHOOK_SECRET = process.env.BILLPADI_WEBHOOK_SECRET;

// Use express.raw to preserve exact raw bytes for signature validation
app.post("/webhooks/billpadi", express.raw({ type: "*/*" }), (req, res) => {
  const signature = req.headers["x-webhook-signature"];
  const timestamp = req.headers["x-webhook-timestamp"];
  const rawBody = req.body.toString("utf8");

  if (!signature || !timestamp) {
    return res.status(400).send("Missing signature headers");
  }

  // Prevent replay attacks (5 minute window)
  if (Math.abs(Date.now() - Number(timestamp)) > 300000) {
    return res.status(401).send("Timestamp expired");
  }

  const message = `${timestamp}.${rawBody}`;
  const expectedSignature = crypto
    .createHmac("sha256", WEBHOOK_SECRET)
    .update(message)
    .digest("hex");

  const isValid = crypto.timingSafeEqual(
    Buffer.from(signature, "hex"),
    Buffer.from(expectedSignature, "hex")
  );

  if (!isValid) {
    return res.status(401).send("Invalid signature");
  }

  const eventPayload = JSON.parse(rawBody);
  console.log("Verified webhook event:", eventPayload.event);

  // Process event asynchronously on your end
  handleEventAsync(eventPayload);

  // Acknowledge receipt immediately with HTTP 200
  res.status(200).json({ received: true });
});
import hmac
import hashlib
import time
from fastapi import FastAPI, Request, HTTPException

app = FastAPI()
WEBHOOK_SECRET = "your_webhook_secret_here"

@app.post("/webhooks/billpadi")
async def handle_webhook(request: Request):
    signature = request.headers.get("x-webhook-signature")
    timestamp = request.headers.get("x-webhook-timestamp")
    
    if not signature or not timestamp:
        raise HTTPException(status_code=400, detail="Missing signature headers")

    if abs(time.time() * 1000 - int(timestamp)) > 300000:
        raise HTTPException(status_code=401, detail="Timestamp expired")

    raw_body = (await request.body()).decode("utf-8")
    message = f"{timestamp}.{raw_body}".encode("utf-8")
    expected = hmac.new(WEBHOOK_SECRET.encode("utf-8"), message, hashlib.sha256).hexdigest()

    if not hmac.compare_digest(signature, expected):
        raise HTTPException(status_code=401, detail="Invalid signature")

    payload = await request.json()
    # Process payload...
    return {"received": True}

Delivery retry policy

  • Your endpoint must return an HTTP status code in the 2xx range within 10 seconds.
  • If your endpoint times out or returns any non-2xx status code, Billpadi retries up to 3 times (at 5 minutes, 15 minutes, and 60 minutes).
  • You can inspect all dispatch attempts, response codes, and payloads in real time via GET /partner/webhooks.
