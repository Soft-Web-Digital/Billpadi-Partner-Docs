Product · Global Airtime & Data

International Top-Up

Send mobile airtime and data bundles to hundreds of destinations worldwide with real-time foreign exchange conversion and carrier routing.

Base paths/api/v1/partner/intl-airtime · /api/v1/partner/intl-data
Authx-api-key (+ x-signature on purchases)
Rate limit30 requests / 60s per namespace
Webhooksinternational.airtime.success · international.data.success

Part 1 — International Airtime

List supported countries

GET /partner/intl-airtime/countries
API key only

List airtime providers for country

GET /partner/intl-airtime/providers
API key only
Query ParamTypeRequiredDescription
countryCodestringrequired2-letter ISO country code (e.g. GH, KE, GB, US)
cURL
curl "https://api.billpadi.com/api/v1/partner/intl-airtime/providers?countryCode=GH" \
  -H "x-api-key: $API_KEY"
Example response — 200 OK
{
  "success": true,
  "message": "Providers retrieved",
  "data": [
    { "operatorId": "mtn-gh", "name": "MTN Ghana", "countryCode": "GH" },
    { "operatorId": "vodafone-gh", "name": "Telecel Ghana", "countryCode": "GH" }
  ],
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/intl-airtime/providers"
}

List airtime products / variations

GET /partner/intl-airtime/products
API key only
Query ParamTypeRequiredDescription
providerIdstringrequiredOperator ID from providers list (e.g. mtn-gh)
productTypeIdintegerrequiredProduct type identifier (e.g. 1 for top-up)

Purchase international airtime

POST /partner/intl-airtime/purchase
Signature required
FieldTypeRequiredDescription
phonestringrequiredFull international MSISDN including country code (e.g. 233201234567)
amountnumberrequiredAmount to send
countryCodestringrequired2-letter ISO country code (e.g. GH)
operatorIdstringrequiredCarrier operator ID (e.g. mtn-gh)
productCodestringrequiredProduct code from products catalog
countryNamestringoptionalCountry name
variationCodestringoptionalDenomination/variation code if applicable
partnerReferencestringrequiredUnique reference string (2–100 characters) for idempotency
cURL
curl -X POST https://api.billpadi.com/api/v1/partner/intl-airtime/purchase \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "phone": "233201234567",
    "amount": 20,
    "countryCode": "GH",
    "countryName": "Ghana",
    "operatorId": "mtn-gh",
    "productCode": "mtn-gh-airtime",
    "partnerReference": "PR-IA-91234"
  }'
Example response — 200 OK
{
  "success": true,
  "message": "International airtime purchase successful",
  "data": {
    "transactionReference": "TXN_1720603200000_9C0D",
    "partnerReference": "PR-IA-91234",
    "status": "success",
    "countryCode": "GH",
    "amount": 20
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/intl-airtime/purchase"
}

Get international airtime status

GET /partner/intl-airtime/transactions/:reference
API key only
