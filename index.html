Partner API · Developer Docs

Build fintech and bill-payment features on our rails

The Partner API empowers your platform to automate wallet deposits, bank payouts, crypto trading, identity verification (NIN/BVN), gift cards, airtime, mobile data, electricity tokens, cable TV, betting wallets, education PINs, and international top-ups — with clean human-readable slugs, a unified HMAC-SHA256 signature scheme, and real-time webhook callbacks.

Base URLhttps://partner-api.billpadi.com/api/v1/partner
Authx-api-key header, HMAC-SHA256 request signing
Formatapplication/json in, JSON envelope out
Rate limit30 requests / 60s per route group (with failure circuit breaker)

All partner API requests are served under /api/v1/partner. Make sure to include your assigned x-api-key in the header of every request.

How it fits together

Every service and product group follows a predictable, battle-tested pattern:

  • Catalog / lookup endpoints (networks, packages, providers, rates, countries) — read-only operations that require only your x-api-key. Use clean slugs like mtn, dstv, ikeja-electric, or bet9ja.
  • Action endpoints (purchase, sell, fund, withdraw, verify) — write operations that move funds or verify identity. These require your x-api-key plus an HMAC-SHA256 signature in the x-signature header.
  • Status & listing endpoints — check any transaction status instantly by its reference, or retrieve paginated lists of past activity.
  • Webhook notifications — asynchronous completion events (e.g. electricity meter tokens, gift card approvals, bank transfer settlements) are delivered straight to your webhook URL signed with your webhookSecret.

Every response is wrapped in a consistent JSON envelope, and every write endpoint requires a unique partnerReference so you can reconcile records against your database seamlessly.

A typical integration

  1. Register at POST /partner/auth/register (account activates immediately — no waiting period) — see Getting Started.
  2. Check your active API scopes and KYC Level under Settings → Developer & API in the Billpadi Web App or via GET /partner/scopes.
  3. Generate your API key pair in Settings or via POST /partner/api-keys, and configure your IP whitelist.
  4. Sign every write request with your secret — see Authentication & Signing.
  5. Configure your webhook endpoint via PATCH /partner/webhook to receive real-time notifications for completed transactions — see Webhooks.
  6. Handle responses, pagination envelopes, and rate limits gracefully — see Errors & Status Codes and Rate Limits.

Production API keys are prefixed with sk_live_… and move real funds. We recommend testing your signature calculation and webhook handling with low denomination transactions first.
