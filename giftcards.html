Product · Digital Cards

Gift Cards

Purchase digital gift cards for top international brands, or accept gift cards from your users for redemption with automated payout and webhook trade updates.

Base path/api/v1/partner/giftcards
Authx-api-key (+ x-signature on purchase/sell)
Max amount₦1,000,000 per transaction
Webhooksgiftcard.sale.approved · giftcard.sale.declined

1. List Gift Card Products

Query the catalog of digital cards with support for pagination and type filtering:

List available gift cards

GET /partner/giftcards/products
API key only
Query ParamTypeDefaultDescription
typestringbuyFilter by trade direction: buy or sell
categorystring—Filter by category ID
pageinteger1Page number
limitinteger20Results per page
cURL
curl "https://api.billpadi.com/api/v1/partner/giftcards/products?type=buy&page=1&limit=20" \
  -H "x-api-key: $API_KEY"

2. Purchase a Gift Card

Purchase digital codes instantly using your main partner wallet balance:

Purchase digital gift card

POST /partner/giftcards/purchase
Signature required
FieldTypeRequiredDescription
giftCardIdstring (ObjectId)required24-character hexadecimal ID from products catalog
productIdstring (ObjectId)optionalOptional variant ID (if card has specific denominations)
amountnumberrequiredCard face value in foreign currency (e.g. 50 USD)
quantityintegerrequiredNumber of cards (1 to 10)
partnerReferencestringrequiredUnique reference string (2–100 characters) for idempotency
cURL
Node.js
curl -X POST https://api.billpadi.com/api/v1/partner/giftcards/purchase \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "giftCardId": "64f1a2b3c4d5e6f7a8b9c0d1",
    "amount": 50,
    "quantity": 1,
    "partnerReference": "PR-GC-10293"
  }'
const res = await partnerClient.post("/giftcards/purchase", {
  giftCardId: "64f1a2b3c4d5e6f7a8b9c0d1",
  amount: 50,
  quantity: 1,
  partnerReference: "PR-GC-10293"
});
Example response — 201 Created

3. Sell a Gift Card

Submit customer gift card redemption details and images for automated processing and review:

Submit gift card for sale

POST /partner/giftcards/sell
Signature required
FieldTypeRequiredDescription
giftCardIdstring (ObjectId)required24-character hexadecimal ID
amountnumberrequiredFace value of the card
quantityintegerrequiredNumber of cards (1 to 10)
cardsarray<string>required1 to 10 URLs pointing to card front/back images or receipts
commentstringoptionalOptional redemption note (e.g. e-code details)
partnerReferencestringrequiredUnique reference string for idempotency
cURL
curl -X POST https://api.billpadi.com/api/v1/partner/giftcards/sell \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "giftCardId": "64f1a2b3c4d5e6f7a8b9c0d1",
    "amount": 100,
    "quantity": 1,
    "cards": ["https://cdn.yourdomain.com/uploads/card-front.jpg"],
    "comment": "Physical card with purchase receipt",
    "partnerReference": "PR-GCS-88213"
  }'
Example response — 201 Created
{
  "success": true,
  "message": "Giftcard sold successfully",
  "data": {
    "transactionReference": "TXN_1720603200000_7C12",
    "partnerReference": "PR-GCS-88213",
    "status": "pending_manual"
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/giftcards/sell"
}

When the card is reviewed, Billpadi fires a giftcard.sale.approved webhook (and credits your wallet) or a giftcard.sale.declined webhook with the decline reason — see Webhooks.
