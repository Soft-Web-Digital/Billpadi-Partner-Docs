Getting started

Four steps to your first live transaction: register, check your KYC scopes, generate your API key pair, and sign your first write request.

Step 1 — Register as a partner

Self-register with your business and representative contact details. This is a public endpoint — no API key is required yet. Your partner account is activated immediately upon registration — there is no waiting period.

Step 2 — Check your API scopes & KYC Level

There is no approval waiting period — your partner account is active immediately. API capabilities and route access are evaluated dynamically based on your account's compliance status. Below are the default baseline guidelines:

Baseline Tier Standard Requirements Accessible API Capabilities / Scopes
Tier 1 Basic registration & email verification (Instant) Read-only public catalog lookups, telecom packages, electricity DISCOs, giftcard rates, and crypto market rates (catalog).
Tier 2 BVN or NIN verification (Instant via KYC API or Webapp) All Bill Payments (Airtime, Data, Cable TV, Electricity, Betting, Education), Gift Cards (Buy/Sell), and Wallet Withdrawals / Bank Transfers.
Tier 3 Government ID, Proof of Address, and CAC Registration Certificate Cryptocurrency Trading (Buy/Sell) and Customer Identity Verification (NIN/BVN lookup) APIs.

Dynamic Requirements & Source of Truth: Requirements and enabled capabilities are configured dynamically on the platform. Always check your live scopes, active KYC tier, and missing document requirements in the web app under Settings → Developer & API, or inspect them programmatically via GET /partner/scopes.

Step 3 — Log in and generate an API key pair

Authenticate with your email and password via standard login to acquire a JWT bearer token for account configuration, or generate keys directly from the Web App dashboard under Settings → Developer & API.

Log in to your account

POST /api/v1/auth/login
Public
FieldTypeRequired
emailstringrequired
passwordstringrequired

With your session token, call POST /partner/api-keys to generate your active API key and secret:

Generate or rotate your API key

POST /partner/api-keys
Dashboard Bearer Auth

This returns your apiKey (e.g. sk_live_...) and apiSecret in plain text. Store both in your encrypted secret store immediately — for security, the API secret is hashed in our database and cannot be retrieved again.

cURL
curl -X POST https://partner-api.billpadi.com/api/v1/partner/api-keys \
  -H "Authorization: Bearer <your-login-token>"
Example response — 200 OK

Calling POST /partner/api-keys rotates your credentials. Any previously active API key is immediately revoked.

Recommended for Live Production: Whitelist your backend server IP addresses via PUT /partner/ip-whitelist or under Settings → Developer & API. Once configured, requests from any unauthorized IP are instantly blocked with 403 Forbidden even if your API key is compromised.

Step 4 — Make your first API request

Read operations (such as listing telecom networks or electricity DISCOs) require only the x-api-key header directed to https://partner-api.billpadi.com:

cURL
curl https://partner-api.billpadi.com/api/v1/partner/airtime/networks \
  -H "x-api-key: sk_live_1f9c2a7e4b6d0f83a5c1e9b7d4f2038a..."

For write actions (airtime top-up, bill payments, payouts, crypto trades), you must sign the JSON body with your apiSecret and pass the HMAC hash in x-signature. Proceed to Authentication & Signing to view code examples for Node.js, Python, PHP, and Go.
