Errors & status codes

Every response in the Partner API adheres to a unified JSON envelope pattern, simplifying client-side error handling, pagination, and debugging.

Response envelopes

Successful single-resource responses:

Standard Success (200 / 201)
{
  "success": true,
  "message": "Airtime purchase initiated",
  "data": {
    "reference": "TXN_1720603200000_A1B2C3",
    "partnerReference": "PR-9182734",
    "status": "pending",
    "amount": 500,
    "totalCost": 485,
    "network": "mtn"
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/airtime/purchase"
}

Paginated collection responses (e.g. gift card products, transaction lists, KYC logs):

Paginated Success (200 OK)
{
  "success": true,
  "message": "Transactions retrieved",
  "data": [
    {
      "reference": "TXN_1720603200000_A1B2C3",
      "status": "success",
      "amount": 500,
      "type": "airtime"
    }
  ],
  "pagination": {
    "total": 142,
    "page": 1,
    "limit": 20,
    "totalPages": 8,
    "hasNext": true,
    "hasPrev": false
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/airtime/transactions"
}

Validation and business rule errors:

Validation Error (400 Bad Request)
{
  "success": false,
  "message": "Amount must not exceed 1000000",
  "error": "VALIDATION_ERROR",
  "details": null,
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/airtime/purchase"
}

Authentication and signature rejections:

Auth Error (401 Unauthorized)
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid signature"
  }
}

HTTP status codes

StatusMeaning
200OK — Request succeeded (read queries, status lookups).
201Created — Resource or transaction successfully created (registration, purchase, sell, beneficiary account).
400Bad Request — Missing parameter, validation failed, or business logic violated.
401Unauthorized — Missing/invalid x-api-key, bad signature, or timestamp skew > 5 mins.
403Forbidden — Origin IP address is not whitelisted, or partner account is pending approval / suspended.
404Not Found — Target resource, slug, or transaction reference was not found.
409Conflict — Duplicate reference or conflicting resource state.
429Too Many Requests — Route rate limit exceeded (30 req / 60s) or failure circuit breaker tripped.
500Internal Server Error — Unexpected server error.
502Bad Gateway — Downstream telecommunications/utility carrier error.
503Service Unavailable — Provider maintenance or offline upstream gateway.

Idempotent retries

Always provide a unique partnerReference on every write request. In case of network drops or client-side HTTP timeouts, retry using the same partnerReference. Our system detects the existing reference and returns the original transaction record without initiating duplicate wallet deductions.
