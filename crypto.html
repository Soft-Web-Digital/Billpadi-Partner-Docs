Product · Digital Assets

Crypto Trading

Programmatically buy and sell Bitcoin, Ethereum, USDT, and USDC with institutional liquidity, real-time rate feeds, multi-network settlement, and webhook trade callbacks.

Base Path/api/v1/partner/crypto
Authx-api-key (+ x-signature on buy/sell)
Supported AssetsBTC, ETH, USDT (TRC20, ERC20, BEP20), USDC
Webhookscrypto.purchase.success · crypto.sale.approved · crypto.sale.declined

2. Calculate Trade Breakdown

Preview exact costs, network fees, and conversion amounts before placing a live order:

Calculate rate & fee breakdown

POST /partner/crypto/breakdown
API Key only
FieldTypeRequiredDescription
cryptoIdstring (ObjectId)required24-character hexadecimal ID of the cryptocurrency
tradeTypestringrequiredbuy or sell
networkIdstringrequiredSelected blockchain network (e.g. net_trc20)
cryptoAmountnumbereither/orAmount in crypto units (e.g. 100)
amountnumbereither/orAmount in NGN fiat (alternative to cryptoAmount)
cURL
curl -X POST https://api.billpadi.com/api/v1/partner/crypto/breakdown \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -d '{
    "cryptoId": "665f3a019e1b2c0012a4ec01",
    "tradeType": "buy",
    "networkId": "net_trc20",
    "cryptoAmount": 100
  }'
Example response — 200 OK
{
  "success": true,
  "message": "Breakdown calculated successfully",
  "data": {
    "cryptoAmount": 100,
    "fiatAmount": 158050.00,
    "rate": 1580.50,
    "networkFee": 1.0,
    "totalCost": 159630.50
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/crypto/breakdown"
}

3. Buy Crypto

Purchase crypto using your partner NGN wallet balance and disburse it to an external destination blockchain address:

Execute crypto purchase

POST /partner/crypto/buy
Signature required
FieldTypeRequiredDescription
cryptoIdstring (ObjectId)required24-character hexadecimal ID
networkIdstringrequiredBlockchain network ID
walletAddressstringrequiredDestination blockchain wallet address
cryptoAmountnumbereither/orCrypto units to buy
amountnumbereither/orEquivalent NGN fiat to spend
partnerReferencestringrequiredUnique reference for idempotency
cURL
curl -X POST https://api.billpadi.com/api/v1/partner/crypto/buy \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "cryptoId": "665f3a019e1b2c0012a4ec01",
    "networkId": "net_trc20",
    "walletAddress": "TQn9Y2khEsLJW1ChVWFMSMeRDow5KcbLSE",
    "cryptoAmount": 100,
    "partnerReference": "CRYPTO-BUY-9921"
  }'
Example response — 200 OK
{
  "success": true,
  "message": "Crypto purchase initiated successfully",
  "data": {
    "reference": "CRYPTO_1720603200000_AA1",
    "partnerReference": "CRYPTO-BUY-9921",
    "status": "pending",
    "cryptoAmount": 100,
    "fiatAmount": 158050.00,
    "walletAddress": "TQn9Y2khEsLJW1ChVWFMSMeRDow5KcbLSE",
    "network": "TRC20"
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/crypto/buy"
}

4. Sell Crypto

Initiate a sell order to receive a dedicated deposit address. Once the crypto arrives on-chain and confirms, your NGN wallet is automatically credited:

Initiate crypto sale

POST /partner/crypto/sell
Signature required
FieldTypeRequiredDescription
cryptoIdstring (ObjectId)required24-character hexadecimal ID
networkIdstringrequiredDeposit blockchain network
cryptoAmountnumbereither/orCrypto units to sell
amountnumbereither/orEquivalent NGN fiat expected
bankAccountIdstringoptionalOptional saved payout account (if disbursing directly to bank)
partnerReferencestringrequiredUnique reference for idempotency
cURL
curl -X POST https://api.billpadi.com/api/v1/partner/crypto/sell \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "cryptoId": "665f3a019e1b2c0012a4ec01",
    "networkId": "net_trc20",
    "cryptoAmount": 250,
    "partnerReference": "CRYPTO-SELL-7712"
  }'
Example response — 200 OK
{
  "success": true,
  "message": "Crypto sale initiated. Send crypto to the provided deposit address.",
  "data": {
    "reference": "CRYPTO_1720603200000_BB2",
    "partnerReference": "CRYPTO-SELL-7712",
    "status": "pending",
    "depositAddress": "TJYeK2khEsLJW1ChVWFMSMeRDow5KcbXYZ",
    "cryptoAmount": 250,
    "fiatAmount": 391250.00,
    "rate": 1565.00
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/crypto/sell"
}
