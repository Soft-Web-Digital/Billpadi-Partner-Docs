Wallet & Identity

Identity Verification (KYC)

Verify end-user identities in real time against Nigerian identity databases (NIN and BVN) to satisfy compliance, AML, and onboarding requirements.

Base Path/api/v1/partner/kyc
Authx-api-key (+ x-signature on verify)
Supported ID Typesbvn · nin
Rate limit30 requests / 60s (failure circuit breaker)

Verify Customer Identity

Perform an identity verification query by passing the customer's BVN or NIN along with their legal name and date of birth:

Verify customer BVN or NIN

POST /partner/kyc/verify
Signature required
FieldTypeRequiredDescription
identificationTypestringrequiredbvn or nin (case-insensitive)
valuestringrequired11-digit BVN or NIN number
firstnamestringrequiredClaimed first name
lastnamestringrequiredClaimed last name
middlenamestringoptionalClaimed middle name (if available)
dateOfBirthstringrequiredFormat: YYYY-MM-DD
phoneNumberstringoptionalCustomer phone number for cross-matching
partnerReferencestringoptionalUnique reference for tracking the verification event
cURL
Node.js
curl -X POST https://api.billpadi.com/api/v1/partner/kyc/verify \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -H "x-timestamp: $TIMESTAMP" \
  -H "x-signature: $SIGNATURE" \
  -d '{
    "identificationType": "bvn",
    "value": "22198765432",
    "firstname": "Chinedu",
    "lastname": "Okeke",
    "dateOfBirth": "1994-08-22",
    "phoneNumber": "+2348031234567",
    "partnerReference": "KYC-USER-10294"
  }'
const res = await partnerClient.post("/kyc/verify", {
  identificationType: "bvn",
  value: "22198765432",
  firstname: "Chinedu",
  lastname: "Okeke",
  dateOfBirth: "1994-08-22",
  partnerReference: "KYC-USER-10294"
});
