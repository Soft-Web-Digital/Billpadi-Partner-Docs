Guide

Account & dashboard

Manage your partner business credentials, retrieve your webhook secret, rotate API keys, inspect main wallet balance, and review webhook delivery logs.

These account-management endpoints are authenticated with your Dashboard Login JWT Token (obtained from POST /api/v1/auth/login) using the standard Authorization: Bearer <token> header.

Partner profile & webhook secret

Get partner profile

GET /partner/profile
Dashboard Bearer Auth

Returns your partner registration status, representative details, KYC tier, active scopes, configured webhook URL, and your active webhookSecret:

cURL
curl https://partner-api.billpadi.com/api/v1/partner/profile \
  -H "Authorization: Bearer <your-login-token>"

API Scopes & Capabilities

Get unlocked API scopes

GET /partner/scopes
Dashboard Bearer Auth

Returns the real-time list of service scopes enabled for your account based on your verified KYC Tier and approved business compliance documents. You can also inspect your live scopes, current KYC tier, and any pending requirements directly in the Billpadi Web App under Settings → Developer & API.

curl https://partner-api.billpadi.com/api/v1/partner/scopes \

IP whitelist management

Billpadi enforces network-level IP whitelisting for your API keys. When configured, any request sent from an IP address not in your whitelist is immediately rejected with 403 Forbidden.

Update authorized IP addresses

PUT /partner/ip-whitelist
Dashboard Bearer Auth

Send an array of exact IPv4/IPv6 addresses or CIDR blocks. Set to [] (empty array) to disable IP restrictions during sandbox testing:

cURL
Node.js
curl -X PUT https://partner-api.billpadi.com/api/v1/partner/ip-whitelist \
  -H "Authorization: Bearer <your-login-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "allowedIps": [
      "102.89.44.12",
      "197.210.55.0/24"
    ]
  }'
const res = await fetch("https://partner-api.billpadi.com/api/v1/partner/ip-whitelist", {
  method: "PUT",
  headers: {
    "Authorization": "Bearer ",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    allowedIps: ["102.89.44.12", "197.210.55.0/24"]
  })
});
const data = await res.json();
Example response — 200 OK
{
  "success": true,
  "message": "IP whitelist updated successfully",
  "data": {
    "allowedIps": [
      "102.89.44.12",
      "197.210.55.0/24"
    ],
    "count": 2
  },
  "timestamp": "2026-07-10T09:20:03.000Z",
  "path": "/api/v1/partner/ip-whitelist"
}

API key management

Generate or rotate API key

POST /partner/api-keys
Dashboard Bearer Auth

Returns a newly generated apiKey and apiSecret pair. Store the secret immediately in your environment secrets manager; it is encrypted at rest and cannot be recovered if lost.

List active API keys

GET /partner/api-keys
Dashboard Bearer Auth

Returns your active key metadata (ID, masked prefix, status, and creation date).

Deactivate an API key

DELETE /partner/api-keys/:keyId
Dashboard Bearer Auth
